1. Общие положения

Настоящая Политика конфиденциальности определяет порядок обработки и защиты персональных данных пользователей сайта arescraftx.online (далее — «Сайт»), принадлежащего проекту AresCraftX.

Используя Сайт, вы подтверждаете своё согласие с условиями данной Политики. Если вы не согласны — пожалуйста, прекратите использование Сайта.

2. Какие данные мы собираем

Данные, предоставляемые вами

  • Имя пользователя — отображаемый никнейм на сайте
  • Email-адрес — для авторизации и уведомлений
  • Дата рождения — по желанию, для подтверждения возраста
  • Пол — по желанию
  • Minecraft-ник — по желанию, для привязки к игровому профилю
  • Описание профиля — по желанию
  • Аватар — по желанию

Данные, собираемые автоматически

  • IP-адрес — для обеспечения безопасности
  • User-Agent — браузер и операционная система
  • Данные об устройстве — тип устройства для управления сессиями
  • Cookie — для поддержания сессии и предпочтений (см. Cookie-политику)
  • Онлайн-статус на сервере — через публичное API mcstatus.io

3. Цели обработки данных

Мы обрабатываем ваши данные в следующих целях:

  • Регистрация и авторизация на Сайте
  • Управление профилем пользователя
  • Обеспечение безопасности аккаунта (2FA, управление сессиями)
  • Предоставление доступа к серверу Minecraft
  • Отправка уведомлений (с вашего согласия)
  • Ведение журнала безопасности (логи входов, изменений)
  • Улучшение работы Сайта и сервиса

4. Защита данных

Мы принимаем следующие меры для защиты ваших данных:

  • Шифрование — все данные передаются по HTTPS (TLS)
  • Row Level Security — каждый пользователь имеет доступ только к своим данным
  • Двухфакторная аутентификация (2FA) — дополнительная защита аккаунта
  • Управление сессиями — просмотр и завершение активных сессий
  • Хеширование паролей — пароли хранятся в зашифрованном виде (Supabase Auth)
  • Санитизация ввода — все пользовательские данные очищаются от потенциально опасного кода
  • Content Security Policy — защита от XSS-атак

5. Передача данных третьим лицам

Мы не продаём, не передаём и не раскрываем ваши персональные данные третьим лицам, за исключением:

  • Supabase — хранение и обработка данных (база данных, авторизация). Серверы расположены в ЕС. Политика Supabase
  • mcstatus.io — публичное API для получения информации о сервере Minecraft (не передаём персональные данные)
  • EmailJS — отправка email-подтверждений (если включено)
  • Требований законодательства Республики Беларусь

6. Хранение данных

Данные хранятся в течение всего времени использования сервиса. Сессии, неактивные более 30 дней, удаляются автоматически. Журналы безопасности хранятся до 90 дней.

Вы можете запросить удаление своих данных, связавшись с нами (см. раздел 8).

7. Международная передача данных

Данные обрабатываются на серверах Supabase (ЕС). При использовании Сайта из Республики Беларусь ваши данные могут передаваться в ЕС в соответствии с применимым законодательством.
