About the Project

AresCraftX — more than a server

AresCraftX is an ecosystem of Minecraft projects, starting with a Java Edition server and expanding to a launcher, anti-cheat and communication platform.

The project was founded in 2021, but soon closed. In 2025 there was an attempt to reopen — the server ran for 6 days and then closed. On June 24, 2025 the project was restarted, and now in 2026 a complete overhaul from scratch has begun.

The server supports versions 1.20–1.21.11 Java Edition and will be available at play.arescraftx.online.
